팟캐스트 메타데이터

이 정보는 본인 repo 의 docs/podcast.json 에 저장되어 RSS feed.xml 의 채널 메타 (제목 / 작성자 / 커버 이미지 등) 가 됩니다. 저장 시 워크플로가 자동 트리거되어 feed 가 재빌드됩니다.

푸시된 에피소드

repo 의 docs/episodes/ 에 저장된 음성개요 목록. 클릭으로 정렬, 노트북별 그룹, 다중 선택 삭제 가능. 편집은 파일명 (날짜·노트북·제목) 변경이라 RSS GUID 가 새로 잡혀 팟캐스트 앱에서 새 에피소드로 보일 수 있습니다.
