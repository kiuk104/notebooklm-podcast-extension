GitHub 연결

PAT + repo 입력 → [저장] → [설정 검증] 으로 push 권한 확인. RSS feed URL 도 여기서 확인/복사.

🔄 다기기 동기화 (Chrome Sync): 이 페이지의 GitHub 설정 (PAT 포함) + UI 언어는 chrome.storage.sync 에 저장되어 같은 Google 계정으로 로그인한 다른 Chrome 의 같은 익스텐션과 자동 공유됩니다. PAT 보안: Chrome Sync 패스프레이즈 를 켜두면 end-to-end 암호화로 Google 도 못 읽음. 안 켜져 있으면 Google 계정 키로 암호화 (이론상 Google 접근 가능). 진행 상태 / 스캔 결과 / 노트북 URL 맵 같은 기기별 데이터는 동기화 안 됨.
[모든 노트북 스캔] 직후 repo 에 없는 카드들을 그대로 이어서 다운로드 + push 합니다 (v1 cron 동등). 첫 사용 시 수십~수백 개가 한꺼번에 들어올 수 있어 default 는 OFF — 수동 검수 후 [신규 받기] 클릭이 안전.

팟캐스트 메타

repo 의 docs/podcast.json 에 저장되어 RSS feed.xml 의 채널 메타 (제목 / 작성자 / 커버 이미지 등) 가 됩니다. 저장 시 워크플로가 자동 트리거되어 feed 가 재빌드됩니다.

에피소드 목록

repo 의 docs/episodes/ 에 저장된 음성개요 목록. 클릭으로 정렬, 노트북별 그룹, 다중 선택 삭제 가능. [편집] 은 해당 NotebookLM 노트북을 새 탭으로 열어 — 제목/내용은 거기서 직접 수정하시고, 잘못 받은 카드는 여기서 삭제 후 다음 sweep 에서 새로 받습니다.
